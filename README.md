# Hostal Nuevo Amanecer

## Integrante

* Gonzalo Exequiel Bautista

## Descripción

**Hostal Nuevo Amanecer** es un sitio web informativo y de reservas para un hostal ubicado en la zona de Laguna Colorada, Bolivia.

El proyecto tiene como objetivo presentar de manera clara y atractiva la información del hostal, sus habitaciones y los servicios disponibles, permitiendo a los visitantes conocer las opciones de alojamiento y realizar una solicitud de reserva mediante un formulario de contacto.

## Tecnologías

* HTML
* CSS
* JavaScript
* Git
* GitHub

## Secciones

* Inicio
* Acerca del hostal
* Habitaciones
* Contacto y reservas

## Funcionalidades

* Visualización de información del Hostal Nuevo Amanecer.
* Presentación de las habitaciones disponibles.
* Formulario para realizar una solicitud de reserva.
* Validación del formulario mediante JavaScript.
* Diseño web adaptable y organizado.
* Navegación mediante un menú principal.

## Objetivo del proyecto

Desarrollar una página web sencilla, funcional y atractiva para presentar los servicios del Hostal Nuevo Amanecer y facilitar el contacto de los visitantes interesados en realizar una reserva.
